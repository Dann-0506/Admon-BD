===============================================================================
 SISTEMA DE INVERSIONES - GUIA DE IMPLEMENTACION Y CAPTURAS
 PostgreSQL 17 y MySQL 8.0 en Windows, dos instancias de cada gestor
===============================================================================

Esta guia lleva, paso a paso, desde los gestores recien instalados hasta el
sistema completo: dos instancias de PostgreSQL y dos de MySQL, con su
esquema, sus datos, la bitacora, los tablespaces, el particionamiento y la
segmentacion. En cada paso se indica que hacer, el comando que se copia y
pega, lo que debe aparecer en pantalla y, cuando corresponde, la captura que
se toma y lo que debe contener.

Sigue los pasos EN ORDEN y sin saltarte ninguno: cada uno depende de los
anteriores.


-------------------------------------------------------------------------------
 0. ANTES DE EMPEZAR
-------------------------------------------------------------------------------

0.1 Contenido de esta carpeta

    GUIA.txt                     Esta guia.
    postgresql\NN_*.sql          Scripts de PostgreSQL (primera instancia).
    postgresql\instancia2\       Scripts exclusivos de la segunda instancia.
    postgresql\consultas\        Consultas para las capturas.
    mysql\...                    Igual, para MySQL.

    No modifiques los .sql: los comandos de la guia los ejecutan tal cual.

0.2 Requisitos

    - PostgreSQL 17 y MySQL 8.0 instalados en el equipo servidor, con los
      instaladores oficiales y sus opciones por defecto (servicios
      postgresql-x64-17 y MySQL80, puertos 5432 y 3306).
    - Las contrasenas de los superusuarios postgres y root.
    - Para los pasos de conexion remota (P19 y M20), otro equipo en la misma
      red con los clientes psql y mysql instalados.

0.3 Terminal

    Usa SIEMPRE "Simbolo del sistema" (cmd) EJECUTADO COMO ADMINISTRADOR, no
    PowerShell. Cada vez que abras una terminal, ejecuta primero:

        chcp 65001
        cd "C:\ruta\donde\esta\esta\carpeta"

    El primer comando hace que se vean bien los acentos; el segundo te
    coloca en la carpeta de esta guia, desde donde funcionan los comandos.

0.4 Como leer cada paso

    Comando:    lo que copias y pegas en la terminal (una linea por comando).
    Resultado:  lo que debe aparecer en pantalla. Si aparece algo distinto,
                en especial un ERROR que no se menciona, DETENTE (ver 0.7).
    Captura:    ruta y nombre con que se guarda la imagen, y lo que debe
                verse en ella.

    Todos los comandos psql y mysql piden la contrasena del usuario que se
    conecta ("Contrasena para usuario ..." o "Enter password:"); escribela y
    presiona Enter. La guia no repite esa linea en los resultados.

    Los mensajes de PostgreSQL pueden aparecer en espanol (por ejemplo,
    "permiso denegado a la tabla pago" en lugar de "permission denied for
    table pago"), segun el idioma de la instalacion. Lo que importa es el
    tipo de mensaje, no el idioma.

0.5 Contrasenas

    dlandero  Dlandero#2026          xzaleta   Xzaleta#2026
    dmejia    Dmejia#2026            enovoa    Enovoa#2026
    pzuniga   Pzuniga#2026           respaldo  Respaldo#2026
    postgres / root: las que se pusieron al instalar.

0.6 Capturas

    Cada captura se guarda en formato .png con la ruta EXACTA que indica el
    paso, dentro de una carpeta "recursos" (por ejemplo
    recursos\02-entorno\pg-version.png). Crea las subcarpetas conforme las
    necesites.

    La captura muestra la ventana de la terminal con el comando y su
    resultado completo. Si el resultado no cabe, maximiza la ventana o reduce
    el tamano de letra antes de tomarla. Los comandos de captura de
    PostgreSQL usan la opcion -e y los de MySQL -t -vvv, para que la
    consulta aparezca junto a su resultado.

0.7 Si algo sale mal

    Los scripts de instalacion se detienen en el primer error. Corrige la
    causa y repite SOLO ese paso.

    Las pruebas (P15 y M16) solo pueden ejecutarse UNA vez. Si una prueba se
    ejecuto dos veces o los datos quedaron mal, reconstruye la base de datos:

      PostgreSQL 1 (cierra antes cualquier otra sesion conectada):
        1) Borra la base de datos:
           psql -h localhost -U postgres -d postgres -c "DROP DATABASE inversiones;"
        2) Solo si ya habias hecho P18, borra los tablespaces (uno por uno):
           psql -h localhost -U postgres -d postgres -c "DROP TABLESPACE ts_catalogos;"
           psql -h localhost -U postgres -d postgres -c "DROP TABLESPACE ts_operacion;"
           psql -h localhost -U postgres -d postgres -c "DROP TABLESPACE ts_bitacora;"
        3) Repite desde P7, SALTANDO P8 (los roles y usuarios ya existen).

      MySQL 1:
        1) Borra la base de datos:
           mysql -h localhost -u dlandero -p -e "DROP DATABASE inversiones;"
        2) Solo si ya habias hecho M19, borra los tablespaces:
           mysql -h localhost -u root -p -e "DROP TABLESPACE ts_catalogos; DROP TABLESPACE ts_operacion; DROP TABLESPACE ts_bitacora;"
        3) Repite M7 y despues desde M11. M8, M9 y M10 no se repiten.


-------------------------------------------------------------------------------
 1. EQUIPO SERVIDOR
-------------------------------------------------------------------------------

E1. Especificaciones del equipo
    Abre Configuracion > Sistema > Informacion.
    Captura: recursos\02-entorno\equipo.png
        Contiene: la ventana "Informacion" con el procesador, la memoria
        instalada y el tipo de sistema (64 bits).

E2. Nombre del equipo
    Comando:
        hostname
    Resultado:
        El nombre del equipo. Anotalo: se usa en P19 y M20.

E3. Firewall
    Comando:
        netsh advfirewall firewall add rule name="PostgreSQL 5432" dir=in action=allow protocol=TCP localport=5432
        netsh advfirewall firewall add rule name="MySQL 3306" dir=in action=allow protocol=TCP localport=3306
    Resultado:
        Aceptar.   (una vez por comando; "Ok." si Windows esta en ingles)

E4. Cuenta de los servicios
    Abre services.msc y revisa la columna "Iniciar sesion como" de los
    servicios postgresql-x64-17 y MySQL80. Lo normal es "Servicio de red".
    Si alguno muestra otra cuenta, usa esa cuenta en lugar de
    "NT AUTHORITY\NetworkService" en los comandos icacls de esta guia.

E5. Directorios de los tablespaces
    Comando:
        mkdir C:\tablespaces\pg1\catalogos
        mkdir C:\tablespaces\pg1\operacion
        mkdir C:\tablespaces\pg1\bitacora
        mkdir C:\tablespaces\mysql1\catalogos
        mkdir C:\tablespaces\mysql1\operacion
        mkdir C:\tablespaces\mysql1\bitacora
        icacls C:\tablespaces\pg1 /grant "NT AUTHORITY\NetworkService:(OI)(CI)F"
        icacls C:\tablespaces\mysql1 /grant "NT AUTHORITY\NetworkService:(OI)(CI)F"
    Resultado:
        mkdir no muestra nada. Cada icacls termina con:
        Se procesaron correctamente 1 archivos; error al procesar 0 archivos

 2. POSTGRESQL - PRIMERA INSTANCIA (puerto 5432)
-------------------------------------------------------------------------------

P1. Variable PATH
    En Configuracion del sistema > Variables de entorno > Path > Nuevo,
    agrega:
        C:\Program Files\PostgreSQL\17\bin
    NO crees la variable PGDATA. Cierra la terminal y abre una NUEVA en una
    carpeta cualquiera (por ejemplo, C:\).
    Comando:
        psql --version
    Resultado:
        psql (PostgreSQL) 17.x
    Captura: recursos\02-entorno\pg-path.png
        Contiene: el comando ejecutado fuera de la carpeta de PostgreSQL y
        la version de psql.
    Vuelve a la carpeta de esta guia (cd, paso 0.3).

P2. Archivo postgresql.conf
    Abre con el Bloc de notas (como administrador):
        C:\Program Files\PostgreSQL\17\data\postgresql.conf
    Busca cada parametro y deja su linea asi. Si la linea empieza con #,
    quita el #. No dupliques lineas.

        listen_addresses = '*'
        port = 5432
        max_connections = 30
        effective_cache_size = 512MB
        max_parallel_workers_per_gather = 0
        idle_in_transaction_session_timeout = 10min
        timezone = 'America/Mexico_City'
        datestyle = 'iso, dmy'

        logging_collector = on
        log_directory = 'log'
        log_filename = 'postgresql-%Y-%m-%d.log'
        log_statement = 'mod'
        log_connections = on
        log_disconnections = on
        log_line_prefix = '%m [%p] %u@%d %r '
        log_timezone = 'America/Mexico_City'

    No cambies ningun otro parametro. Guarda el archivo.

P3. Archivo pg_hba.conf
    Abre como administrador:
        C:\Program Files\PostgreSQL\17\data\pg_hba.conf
    Agrega estas dos lineas DEBAJO de las lineas que contienen 127.0.0.1/32
    y ::1/128, en este orden:

        host    all             postgres        samenet         reject
        host    inversiones     all             samenet         scram-sha-256

    Guarda el archivo.

P4. Reiniciar el servicio
    Comando:
        net stop postgresql-x64-17
        net start postgresql-x64-17
    Resultado:

-------------------------------------------------------------------------------
 3. MYSQL - PRIMERA INSTANCIA (puerto 3306)
-------------------------------------------------------------------------------

Los scripts de MySQL no muestran nada cuando terminan sin errores: la
